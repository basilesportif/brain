# Mercury Skill (Deprecated)

> **This skill has been superseded by the unified [Finance Skill](finance.md).** Mercury is now one provider within the finance skill. Use `config/skills/finance.md` for all banking operations.
>
> For setup, see [setup-finance.md](setup-finance.md).
>
> Legacy Mercury scripts (`mercury-accounts.js`, `mercury-balances.js`, `mercury-transactions.js`) still work as backward-compatible wrappers that call the unified finance scripts with `--provider mercury`.
