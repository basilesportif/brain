# docs

Documentation skeleton for the `brain` control-plane repository.

- `control-plane.md` — Brain as setup/orchestration control plane for the
  `codex-chat` servant runtime stack.
- `architecture.md` — target component boundaries and data flow.
- `directory-structure.md` — intended tree and ownership rules.
- `private-workspace-boundary.md` — what must stay outside git/public packages.
- `provider-abstraction.md` — Codex and Claude Code adapter boundary.
- `setup-plan.md` — agent-readable first install flow and future `brainctl setup` contract.
- `self-hosting.md` — future setup path for self-host users.
- `deployment.md` — server deployment shape and operational constraints.
- `testing.md` — test layers for migration and provider parity.
- `public-readiness.md` — criteria before opening any repo/package publicly.
- `migration.md` — phased migration index; see `plans/` for the living plan.
